# API Documentation

The repository exposes a FastAPI application for knowledge graph operations.

## Swagger UI

Run the app and open:

```text
http://127.0.0.1:8000/docs
```

## Key endpoints

- `GET /health`
- `POST /ingest`
- `GET /search`
- `GET /stats`
- `POST /categories`
- `POST /concepts`
- `POST /claims`
- `POST /evidence`
- `POST /relationships`

For full API details, use the live OpenAPI documentation once the app is running.
