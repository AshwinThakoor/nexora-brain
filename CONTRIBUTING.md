# Contributing to NEXORA Brain

Thank you for your interest in contributing to NEXORA Brain.

## How to contribute

- Open an issue for bugs, improvements, or documentation changes.
- Use descriptive titles and include reproduction steps.
- For code contributions, open a pull request with a clear description of the change.
- Keep changes focused and avoid adding unrelated application features.

## Pull request process

1. Fork the repository.
2. Create a feature branch.
3. Add tests or documentation for your change.
4. Run `python -m pytest` and `python -m compileall .` locally.
5. Submit a pull request and link any related issue.
